# Portfolio Context

## Terms

### Hire Me Command Center

The primary recruiter-facing feature that maps role types to proof: Robotics,
Autonomy, Simulation, and AI Tooling. It should feel like a compact engineering
cockpit, not a generic portfolio card grid.

### Totally Real Reviews

Clearly fictional testimonials used as personality-forward portfolio copy. They
should be funny and obviously fake while staying safe for recruiters.

### Roast Mode

An opt-in terminal/guide interaction for sharper self-aware humor. It is not the
default public tone; the visible site stays hireable first.

### Retro Games Grid

A secondary personality section mixed directly with the regular retro game
cards. External links can point to curated game pages, but the portfolio should
not host game downloads.

### Public CV Gate

A zero-backend human check that reveals the public CV page. It is scraper
friction, not real access control, and the public CV should avoid phone numbers
or unnecessary private details.

### Visual Thesis

The portfolio should read as a calm engineering command center with maker
mischief. The first impression is competent and recruitable; the second layer is
Clippy, terminal, fake reviews, opt-in roast mode, the goose, and retro games.

### Personality Layer

The personality features are secondary affordances. They make the site memorable
without competing with the primary hiring story.
